## 📱 Основные проекты

### 🛠️ [NMedia](../../../NMedia) — Мобильное приложение социальной сети
*Клиент-серверное Android-приложение для публикации постов, взаимодействия с контентом и работы с медиа.*
- **Стек:** Kotlin, Coroutines, Room DB, Retrofit, Architecture Components (ViewModel, LiveData).
- **Что сделано:** Реализовал архитектуру MVVM, настроил локальное кэширование через Room для обеспечения offline-first режима и бесшовную синхронизацию данных с удаленным сервером через REST API.

### 🎨 [StatsView](../../../StatsView) — Кастомный UI-компонент с анимацией
*Проект-демонстрация продвинутой работы с графической системой Android и отрисовкой кастомного интерфейса.*
- **Стек:** Kotlin, Canvas API, Android Animation Framework.
- **Что сделано:** С нуля спроектировал и запрограммировал кастомный графический элемент (`Custom View`) для отображения круговой статистики. Реализовал математический расчет секторов и плавные анимации появления данных.

### ☕ [HW_netology](../../../HW_netology) — Проекты на Java Core
*Комплекс практических задач, подтверждающий знание фундаментальной базы и промышленного ООП.*
- **Стек:** Java SE, Collections, Исключения, Алгоритмы фильтрации данных.
- **Что сделано:** Закрепил на практике принципы ООП, реализовал обработку ошибок и работу со сложными структурами данных (`Lists`, `Queues`, `HashMaps`) для эффективной обработки бизнес-логики.
